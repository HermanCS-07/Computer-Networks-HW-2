# Network_Class

Computer and Networks Homework 2
Simulating a client-server interaction with C++ socket programming
## Installation and Running
1. clone the repo
```bash
git clone https://github.com/HermanCS-07/Computer-Networks-HW-2.git
```

2. Clean the binaries
```bash
make clean
```
3. Compile .cpp source code
```bash
make all
```

4. Testing
On one terminal run the server:
```bash
./server
```
In another terminal, run the client:
```bash
./client
```
